=== A reserved word is not a name
lenient: reject
strict: reject
---
end = 5;

=== Nor is otherwise
lenient: reject
strict: reject
---
otherwise = 5;

=== Nor is until
lenient: reject
strict: reject
---
until = 5;

=== A name may begin with one
lenient: ok
strict: ok
---
endpoint = 5;
untilNow = 1;

=== A reserved word is a field name after a dot
lenient: ok
strict: ok
---
expr = finfo.function;
y = s.end;

=== A method may be named for one
lenient: ok
strict: ok
---
classdef c
  methods (Hidden)
    function n = end (this, d, k)
      n = 1;
    endfunction
  endmethods
endclassdef

=== arguments is an ordinary name
lenient: ok
strict: ok
---
arguments = 5;
x = arguments + 1;
