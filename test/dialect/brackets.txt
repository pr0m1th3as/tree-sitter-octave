=== A space in an anonymous function's body opens no element in Octave
lenient: reject
strict: reject
matlab: ok
---
c = {@(t) t (1) 2};

=== Two anonymous functions in a cell need a comma in Octave
lenient: reject
strict: reject
matlab: ok
---
c = {@(y) mean (y) @(y) std (y)};

=== A backslash does not continue a line
lenient: reject
strict: reject
matlab: reject
---
x = 1 + \
  2;

=== A backslash still continues a double-quoted string
lenient: ok
strict: ok
---
s = "a\
b";

=== A line ending in an operator does not continue
lenient: reject
strict: reject
matlab: reject
---
x = 1 +
  2;

=== Nor inside brackets
lenient: reject
strict: reject
---
x = [1 +
  2];

=== Inside parentheses it does
lenient: ok
strict: ok
---
x = (1 +
  2);

=== Rows may open with a line break and an empty row
lenient: ok
strict: ok
matlab: ok
---
x = [
;1 2];
